# Tech Stack

## Context

Global tech stack defaults for Agent OS projects, overridable in project-specific `.agent-os/product/tech-stack.md`.

## Frontend Framework
- **Next.js** – React-based framework for production-grade applications
  - Server-side rendering (SSR) and static site generation (SSG)
  - Built-in routing and API routes
  - Optimized performance with automatic code splitting
  - Image optimization out of the box

## UI Library
- **React** – Component-based JavaScript library for building user interfaces
  - Declarative and efficient UI development
  - Rich ecosystem of third-party libraries
  - Strong community support

## Backend Framework
- **NestJS** – Progressive Node.js framework built with TypeScript
  - Modular architecture with dependency injection
  - Built-in support for GraphQL, WebSockets, and microservices
  - Extensive CLI for scaffolding and code generation
  - Robust testing utilities

## Language
- **TypeScript** – Strongly typed programming language built on JavaScript
  - Enhanced code quality with static typing
  - Better IDE support and autocomplete
  - Improved maintainability and refactoring

## Database & Backend Services Platform
- **Supabase** – Open-source Firebase alternative
  - **PostgreSQL Database** – Powerful relational database with full SQL support
  - Real-time subscriptions – Live data updates across clients
  - Auto-generated APIs – RESTful API and real-time subscriptions
  - Row Level Security (RLS) – Fine-grained access control at the database level
  - Storage – Object storage for files and media
  - Edge Functions – Serverless functions for custom backend logic

## Authentication
- **Supabase Auth** – Native authentication solution
  - Email/password authentication
  - OAuth providers (Google, GitHub, etc.)
  - Magic link authentication
  - JWT-based sessions
  - Role-based access control (RBAC)
  - Multi-factor authentication (MFA) support

## Deployment & Containerization
- **Docker** – Platform for developing, shipping, and running applications in containers
  - Consistent environments across development, staging, and production
  - Easy scalability and orchestration
  - Isolated dependencies and simplified deployment
  - Multi-stage builds for optimized image sizes

## Version Control Platform
- **GitHub** – Web-based version control and collaboration platform
  - Git-based version control
  - Pull request workflows for code review
  - GitHub Actions for CI/CD pipelines
  - Issue tracking and project management
  - Branch protection and security features
