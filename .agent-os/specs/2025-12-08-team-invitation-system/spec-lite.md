# Spec Summary (Lite)

Implement a team invitation system enabling project owners to invite collaborators via email using Resend. Invitees can accept invitations whether they have existing HCI Hub accounts (via login) or are new users (via registration), with automatic project membership upon acceptance. The system includes a team management UI at `/projects/[id]/team` for sending invitations, viewing pending invitations, and revoking them, with all invitations expiring after 14 days.
