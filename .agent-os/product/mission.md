# Product Mission

## Pitch

HCI Hub is a comprehensive web application that helps HCI and UX Design students plan, execute, and document human-centered design projects by providing structured methodological support, templates, and AI-assisted tools aligned with ISO 9241-210 standards.

## Users

### Primary Customers

- **Master's Students**: Students in HCI, UX Design, or related fields working on semester-long projects
- **Academic Teams**: Project teams collaborating on structured HCI coursework
- **Independent Learners**: Individual learners seeking to understand and apply the HCD process systematically

### User Personas

**Graduate HCI Student** (23-28 years old)
- **Role:** Master's student in Human-Computer Interaction
- **Context:** Working on semester-long HCI project, either individually or in small teams (2-4 people)
- **Pain Points:** Difficulty systematically planning HCI projects, uncertainty about which methods to use in each phase, scattered documentation across multiple tools, lack of structured templates
- **Goals:** Complete high-quality HCI project following ISO 9241-210, learn and apply appropriate HCI methods, maintain organized documentation, collaborate effectively with team members

## The Problem

### Fragmented Project Planning

Students struggle to systematically plan HCI projects according to industry standards. They often don't know which methods are appropriate for each phase of the Human-Centered Design process, leading to inconsistent application of HCD principles and poor project outcomes.

**Our Solution:** An integrated platform that guides students through the ISO 9241-210 process with phase-specific method recommendations and structured workflows.

### Scattered Documentation

HCI project artifacts (personas, user stories, journey maps, prototypes) are typically scattered across multiple tools and formats, making it difficult to maintain coherence and trace design decisions back to research findings.

**Our Solution:** A centralized documentation system with interconnected templates that link artifacts to requirements, personas, and research insights.

### Lack of Methodological Support

Students receive theoretical knowledge about HCI methods but lack practical guidance on how to apply them, including resource requirements, step-by-step instructions, and expected outcomes.

**Our Solution:** A comprehensive method library with detailed application guidelines, filtering by effort level and project phase, and AI-assisted recommendations.

## Differentiators

### ISO 9241-210 Alignment

Unlike generic project management tools, HCI Hub is specifically designed around the Human-Centered Design lifecycle as defined in ISO 9241-210. This provides students with structured guidance that directly maps to industry standards and academic requirements.

### Integrated Documentation Templates

Unlike tools like Figma or Miro that focus on single artifact types, HCI Hub provides interconnected templates for the entire HCD process - from personas to user stories to journey maps to prototypes - ensuring consistency and traceability across all project artifacts.

### AI-Enhanced Learning

Unlike traditional documentation platforms, HCI Hub leverages AI to provide contextual method recommendations, template auto-completion, user story refinement, and documentation quality checks, accelerating learning while maintaining methodological rigor.

## Key Features

### Core Features

- **Process Management Module:** Interactive ISO 9241-210 process visualization with phase indicators, progress tracking, and guided workflows for Analysis → Requirements → Solutions → Evaluation phases
- **Method Library:** Categorized catalog of HCI methods with detailed profiles, filtering by phase/effort/participants, step-by-step guidelines, and comparison tools
- **Project Dashboard:** Centralized view of all project artifacts, milestones, and progress with quick access to current phase tasks

### Documentation Features

- **Persona Builder:** Template-based persona creation with photo upload, structured fields for demographics/goals/behaviors, and PDF/image export
- **User Stories Manager:** Standard format templates ("As a [role], I want [action] so that [benefit]"), acceptance criteria definition, priority assignment, and planning poker integration
- **User Journey Mapping:** Visual journey builder with drag-and-drop interface, emotional curve visualization, phase breakdown, and opportunity identification
- **Requirements Templates:** Documentation tools for user needs, functional/non-functional requirements, conceptual design, and physical design specifications
- **Prototyping Area:** Version control for design iterations, linking to requirements, annotation tools, and Figma embed integration

### AI-Assisted Features

- **Method Recommendations:** AI suggests appropriate methods based on project context and current phase
- **Content Generation:** AI helps generate persona details based on research inputs and refine user stories for quality
- **Documentation Review:** AI quality checks for gaps, inconsistencies, and adherence to best practices

### Collaboration Features

- **Team Management:** Support for multi-user projects with role-based access and shared artifacts
- **Real-time Collaboration:** Live editing and updates using WebSockets and Supabase Realtime
- **Export & Integration:** PDF export, external tool integrations (Figma, Miro), and comprehensive data export capabilities
