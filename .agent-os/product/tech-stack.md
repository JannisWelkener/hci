# Technical Stack

## Frontend

- **Application Framework:** Next.js 15.5.4
- **JavaScript Framework:** React 19.1.0
- **Language:** TypeScript 5
- **Module Strategy:** ES Modules (Next.js bundler)
- **CSS Framework:** Tailwind CSS 4
- **UI Component Library:** shadcn/ui (planned)
- **Fonts Provider:** next/font/google (Geist Sans, Geist Mono)
- **Icon Library:** TBD (lucide-react recommended)
- **State Management:** React Context + TanStack Query (planned)
- **Form Handling:** React Hook Form + Zod validation (planned)

## Backend

- **Framework:** NestJS (planned)
- **Language:** TypeScript
- **API Architecture:** RESTful + GraphQL (optional)
- **Real-time Communication:** WebSockets for collaboration features

## Database & Services

- **Database System:** Supabase (PostgreSQL)
- **Authentication:** Supabase Auth (email/password, OAuth)
- **Storage:** Supabase Storage for file uploads (photos, prototypes, exports)
- **Real-time Subscriptions:** Supabase Realtime for live collaboration

## Development Tools

- **Build Tool:** Turbopack (Next.js built-in)
- **Linting:** ESLint with Next.js config (eslint-config-next)
- **Code Repository:** GitHub
- **Version Control:** Git
