Executive Summary
A comprehensive web application designed to guide students through the Human-Centered Design (HCD) process according to ISO 9241-210 standards. The platform provides structured methodological support, templates, and AI-assisted tools to help students plan, execute, and document HCI projects effectively.
Core Vision
Students often struggle with systematically planning HCI projects and selecting appropriate methods for each phase of the design process. This platform bridges that gap by providing:

A structured, phase-based approach to HCI project planning
A comprehensive library of HCI methods with practical guidance
Integrated tools for creating and managing project artifacts
AI-assisted support throughout the development process

Key User Groups
Primary Users

Master's students in HCI, UX Design, or related fields
Project teams working on semester-long HCI projects
Individual learners seeking to understand the HCD process

Use Cases

Planning and structuring HCI course projects
Learning and applying HCI methods systematically
Documenting design decisions and artifacts
Collaborating on team-based projects

Functional Requirements
1. Process Management Module
Goal: Provide clear navigation through the HCD lifecycle
Features:

Interactive visualization of ISO 9241-210 process model
Phase indicators showing current project stage
Progress tracking with milestone management
Guided workflows for each phase (Analysis → Requirements → Solutions → Evaluation)

User Stories:

As a student, I want to see which phase of the HCD process I'm currently in, so that I understand my project's progress
As a student, I want to navigate between different project phases, so that I can work on tasks in a structured manner
As a team member, I want to track completed milestones, so that our team stays aligned on progress

2. Method Library
Goal: Enable informed selection of appropriate HCI methods
Features:

Categorized method catalog by project phase
Detailed method profiles including:

When to use the method
Required resources (time, participants, materials)
Step-by-step application guidelines
Expected outcomes


Advanced filtering by:

Project phase
Effort level
Number of participants required
Method objectives


Search functionality
Comparison tool for similar methods

User Stories:

As a student, I want to browse methods by project phase, so that I can find appropriate techniques for my current work
As a student, I want to filter methods by effort level, so that I can choose techniques that fit my time constraints
As a student, I want to see detailed guidelines for each method, so that I can apply them correctly

3. Project Documentation System
Goal: Centralize all project artifacts in one accessible location
Features:
Persona Builder

Template-based persona creation
Photo upload capability
Structured fields for demographics, goals, behaviors, and context
Export functionality (PDF/image)

User Stories Manager

Standard format templates ("As a [role], I want [action] so that [benefit]")
Acceptance criteria definition
Priority assignment
Linking stories to personas
Planning poker integration for estimation

User Journey Mapping Tool

Visual journey builder with drag-and-drop interface
Emotional curve visualization
Phase breakdown (touchpoints, actions, thoughts, feelings)
Opportunity identification
Multiple persona journey support

Requirements Templates

User needs documentation
Functional/non-functional requirements
Conceptual design artifacts
Physical design specifications

Prototyping Area

Version control for design iterations
Linking prototypes to requirements
Annotation and feedback tools
Integration with common design tools (Figma embed)

User Stories:

As a student, I want to create personas using templates, so that I can quickly document user research findings
As a student, I want to write user stories in a structured format, so that my requirements are clear and testable
As a student, I want to map user journeys visually, so that I can identify pain points and opportunities
As a team member, I want to see all project artifacts in one place, so that I can easily reference previous work

4. AI-Assisted Features
Goal: Leverage AI to enhance productivity and learning
Features:

Method recommendation based on project context
Template auto-completion suggestions
Content generation for personas (based on research inputs)
User story refinement suggestions
Design critique and feedback
Documentation quality checks

User Stories:

As a student, I want AI to suggest appropriate methods for my project phase, so that I make informed choices
As a student, I want AI to help me refine my user stories, so that they meet quality standards
As a student, I want AI to review my documentation, so that I can identify gaps or inconsistencies

Framework: Next.js 14+ with App Router
UI Library: React 18+
Language: TypeScript
Styling: Tailwind CSS + shadcn/ui components
State Management: React Context + TanStack Query
Form Handling: React Hook Form + Zod validation

Backend

Framework: NestJS
Language: TypeScript
API: RESTful + GraphQL (optional)
Real-time: WebSockets for collaboration features

Database & Services

Database: Supabase (PostgreSQL)
Authentication: Supabase Auth (email/password, OAuth)
Storage: Supabase Storage for file uploads
Real-time subscriptions: Supabase Realtime

Deployment

Containerization: Docker + Docker Compose
Version Control: GitHub
CI/CD: GitHub Actions
Hosting: Vercel (Frontend) + Railway/Render (Backend)

Selects primary persona/user group

Method Selection & Application

User navigates to current project phase
Filters methods by objectives and effort
Reviews method details and guidelines
Adds method to project plan
Executes method and documents findings

Persona Creation

User selects "Create Persona" from project dashboard
Fills template with research findings
AI suggests additional characteristics based on context
Reviews and refines persona
Saves and links to project

Journey Mapping

User selects persona for journey
Defines scenario and goals
Maps touchpoints and phases
Documents actions, thoughts, emotions per phase
Generates emotional curve visualization
Identifies opportunities and pain points
